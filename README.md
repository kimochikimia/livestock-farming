# Livestock Farming — малын аж ахуйн вэб систем

Нэвтрээгүй хүмүүст нүүр хуудас харагдана: сайтын тухай, системийн нийт тоон мэдээлэл (ферм, хэрэглэгч, мал, жинлэлт) болон админы нийтэлсэн мэдээ. Баруун дээд буланд "Нэвтрэх", "Бүртгүүлэх" товч бий. Мэдээг админ **Админ → Мэдээ** цэснээс нийтэлнэ.

Google Sheet ("Тохиргоо", "Малын бүртгэл", "Жинлэлтүүд", "Зардлын бүртгэл", "Бой хуваарь", "Борлуулалт", "Тооцоолол", "Зах зээл суд", "Тэжээл жор-хоног") дээр суурилсан малын бүртгэлийн вэб.

Бүх мэдээллийг гараар оруулна. Вэб хоосон эхэлнэ. Өмнө оруулсан утгуудыг (насны нэршил, зардлын төрөл, малын ID гэх мэт) бичих үед санал болгоно. Тооцоолол (сүүлийн жин, өсөлт, зорилтын төлөв, нийт өртөг, ачигдсан жин, орлого, ашиг, тэжээлийн өртөг) автоматаар хийгдэнэ.

Мал, жинлэлт, зардал, бой, борлуулалтын бүртгэл бүрт зураг хавсаргаж болно. "Зураг оруулах" товч файлаас, "Зураг авах" товч гар утасны камераас шууд авна. Зургийг илгээхээс өмнө 1600px хүртэл багасгадаг. Нэг бүртгэлд хамгийн ихдээ 30 зураг оруулна.

## Ферм

Сайт олон фермтэй. Хэрэглэгч бүртгүүлж, админ баталгаажуулсны дараа **"Миний фермүүд"** хуудаснаас хүссэн тооны ферм үүсгэнэ. Фермээ сонгож ороход доорх бүх цэс тухайн фермийн бүртгэлтэй ажиллана. Мал, жинлэлт, зардал, борлуулалт, ажил болон тохиргоо (малын ангилал, төрлүүд) ферм бүрт тусдаа хадгалагдана.

- Фермийн эзэмшигч өөрийн фермд бүрэн эрхтэй. Бусад хэрэглэгч түүний фермийг харахгүй.
- Сайтын админ бүх фермийг харж, удирдана.
- Шинэ ферм үүсгэхдээ өөр фермийн тохиргоог хуулж болно.
- Ферм устгахад түүний бүх бүртгэл, зураг хамт устна. Баталгаажуулахын тулд фермийн нэрийг бичнэ.
- Фермтэй хэрэглэгчийг устгах боломжгүй. Түүнийг "Хаагдсан" төлөвт оруулна.

## Боломжууд

| Хэсэг | Юу хийдэг |
|---|---|
| Хянах самбар | Нийт зарлага, орлого, ашиг, ашиг хуваарилалт, малын тоо, борлуулахад бэлэн мал |
| Малын бүртгэл | Мал бүртгэх. Сүүлийн жин, өсөлт, өдрийн өсөлт, зорилтот жингийн төлөв ("Борлуулах" / "Хүрээгүй"), нийт өртөг автоматаар тооцогдоно |
| Жинлэлт | Малын жинлэлтийн түүх |
| Зардал | Зардлын бүртгэл (Тоо × Нэгж үнэ) |
| Бой хуваарь | Бойлсон мал, гулуузны жин, ачигдсан огноо |
| Борлуулалт | Ачилтаар нь нэгтгэсэн жин, борлуулсан жин × үнэ = орлого |
| Зах зээл судалгаа | Сар, улирлаар махны үнэ |
| Тэжээл | 90 хоногийн тэжээлийн төлөвлөгөө, өртгийн тооцоо, тэжээлийн жор |
| Хэрэглэгчид *(админ)* | Бүртгэл батлах/татгалзах, эрх олгох, хаах, нууц үг шинэчлэх, устгах |
| Тохиргоо *(админ)* | Малын ангилал ба зорилтот жин, тэжээлийн үнэ, зардлын төрөл, төллөлт, ашиг хуваарилалт, ерөнхий тохиргоо |
| Үйлдлийн түүх *(админ)* | Хэн, хэзээ, юу хийснийг харуулна |

**Эрхүүд:** Админ — бүгдийг удирдана. Бүртгэл хөтлөгч — бүртгэл нэмж, засна. Харагч — зөвхөн харна. Бичлэг устгах эрх зөвхөн админд бий.

**Бүртгэлийн урсгал:** Хэрэглэгч утасны дугаар болон нууц үгээрээ бүртгүүлнэ. Бүртгэл "Хүлээгдэж буй" төлөвтэй үүснэ. Админ "Хэрэглэгчид" хэсгээс эрх сонгоод баталснаар хэрэглэгч нэвтрэх боломжтой болно.

## Компьютер дээрээ ажиллуулах

Node.js 22.13 буюу түүнээс шинэ хувилбар болон **MySQL 8** шаардлагатай. MySQL-ийн холболтыг `.env` файлд (`DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`) тохируулна. Сан болон хүснэгтүүд анх асахад автоматаар үүснэ.

```bash
npm install
npm start          # http://localhost:3080
```

Админыг `.env` файлын `ADMIN_PHONE` / `ADMIN_PASSWORD` утгаар анх эхлэхэд нэг удаа үүсгэнэ. Дараа нь нууц үгийг вэб дээрх "Миний бүртгэл" хэсгээс солино. `.env` файлыг хэнд ч бүү хуваалц.

> `.env` дотор нууц үг `#` тэмдэгт агуулж байгаа бол хашилтанд хийнэ: `ADMIN_PASSWORD="..."`

## Интернэтэд байршуулах

Өгөгдөл **MySQL**-д, зургууд `UPLOAD_DIR` (анхдагч `./data/uploads`) хавтсанд хадгалагдана. Хостинг дээр MySQL үйлчилгээ (Railway MySQL, PlanetScale, VPS дээрх MySQL г.м.) болон зургийн хавтсанд зориулсан **байнгын диск** хэрэгтэй.

Орчны хувьсагчууд:

```
NODE_ENV=production
ADMIN_PHONE=<админы утас>
ADMIN_PASSWORD=<нууц үг>
DB_HOST=…  DB_PORT=3306  DB_USER=…  DB_PASSWORD=…  DB_NAME=tumen_sureg
UPLOAD_DIR=/data/uploads
```

`DB_*` тохируулаагүй бол Railway-ийн MySQL-ийн `MYSQL_URL` эсвэл `MYSQLHOST`, `MYSQLPORT`, `MYSQLUSER`, `MYSQLPASSWORD`, `MYSQLDATABASE` хувьсагчдыг автоматаар ашиглана.

### A. Railway
1. Энэ хавтсыг GitHub-д **private** repo болгож оруулна (`.env` ба `data/` автоматаар орохгүй).
2. Railway → **New Project → Deploy from GitHub repo** → энэ repo. `Dockerfile`-ийг автоматаар танина.
3. Төсөлд **+ New → Database → MySQL** нэмнэ.
4. Вэб үйлчилгээний **Variables**: `MYSQL_URL=${{MySQL.MYSQL_URL}}`, `NODE_ENV=production`, `ADMIN_PHONE`, `ADMIN_PASSWORD`, `UPLOAD_DIR=/data/uploads`.
5. Вэб үйлчилгээнд **Volume** нэмж `/data` зам дээр холбоно (зургууд).
6. **Settings → Networking → Generate Domain** — HTTPS хаяг үүснэ.

### B. Өөрийн VPS (Ubuntu)
```bash
# Node 22+ болон MySQL 8 суулгасны дараа
npm ci --omit=dev
# .env файлд DB_*, ADMIN_*, UPLOAD_DIR=/var/lib/tsfarm/uploads тохируулна
NODE_ENV=production node --env-file=.env server/index.js
```
pm2 эсвэл systemd-ээр байнга ажиллуулж, урд нь nginx + Let's Encrypt (HTTPS) тавина. Production горимд cookie зөвхөн HTTPS-ээр дамждаг.

### Нөөц хуулбар
MySQL санг өдөр бүр нөөцөлнө: `mysqldump -u root -p tumen_sureg > backup.sql`. Мөн `uploads/` хавтсыг хуулна.

### SQLite-аас шилжүүлэх
Хуучин SQLite файлаас MySQL руу нэг удаа шилжүүлэх: `node --env-file=.env server/migrate-sqlite-to-mysql.js data/farm.db`. MySQL санд хэрэглэгч аль хэдийн байвал скрипт зогсоно.

## Аюулгүй байдал
- Нууц үгийг bcrypt-ээр шифрлэж хадгална.
- Session нь httpOnly, SameSite cookie-д хадгалагдана.
- Нэвтрэх/бүртгүүлэх оролдлогыг хязгаарлана (15 минутад 20).
- CSP болон бусад аюулгүй байдлын header-уудыг helmet тохируулна.
- Хэрэглэгчийг хаах, нууц үгийг нь солиход тухайн хэрэглэгчийн бүх нэвтрэлт шууд хаагдана.
